Install it

  1. Download the installer

    Click Download for Windows above. If your browser asks, choose Keep.

  2. Open it from your Downloads

    Double-click APG-Post-It_…_x64-setup.exe. It installs for you only and opens when it's done.

    If Windows says "Windows protected your PC", click More info, then Run anyway. Windows shows this for apps it hasn't seen many times before.

  3. Sign in

    Use the same email and password as Alpha Listing Hub. Don't have an account yet? Ask your admin.

Already have it?

You don't need this page to update. When a new version is out, the app shows Restart and update. You can also click Check for updates in the sidebar.
